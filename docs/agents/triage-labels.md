# Triage labels

| Canonical role | Label in our tracker | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 需要判断问题、范围与下一步 |
| `needs-info` | `needs-info` | 缺少继续处理所需的信息 |
| `ready-for-agent` | `ready-for-agent` | 范围与验收明确，可由 agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或实施 |
| `wontfix` | `wontfix` | 已决定不处理，并记录原因 |

skill 提及上述角色时使用右侧标签。既有 `bug`、`documentation` 等类别标签继续使用，分流标签表示工作状态。
