# Domain docs

DMA_CE 是单一领域项目：术语统一记录在根目录 [GLOSSARY.md](../../GLOSSARY.md)，设计决策按需记录到 `docs/adr/`。

探索或修改代码前，读取术语表及与当前问题有关的 ADR；文件尚不存在时直接继续。输出中的领域概念沿用术语表；出现有实质区别的新概念时使用 `domain-modeling` 澄清定义。

术语表只写概念和含义；配置、公式推导、命令及实验结果分别留在配置文件、方法指南和结果报告。只有难以逆转、缺少背景会令人意外、且确有方案取舍的决定才写 ADR；编号递增，记录当时背景和理由。

建议与现有 ADR 冲突时明确指出对应编号和重开理由。运行说明与历史材料从 [文档索引](../README.md) 按需读取。
