# 研究讨论记录：2026-10-20

这是当时讨论的备选方法与验证问题，不是已经冻结的实验计划。后续实际执行及结果见[实验记录](EXPERIMENT_LOG.md)。

- DMA当前每频点的空间压缩使任意32维信道欠定；物理多径参数具有更低维结构，需要区分任意向量恢复与路径参数可辨识性。
- 当前条件残差网络只接收粗估及条件量，原始观测矩阵、观测和噪声通过外部物理更新参与估计。直接CSI先验与残差先验的训练分布不同。
- Li的宽带展开方法使用AoSA相移器结构与SBL解析后验，不能按DMA方法或DDPM方法直接描述。可讨论保留解析更新、学习方差或协方差调整的具体部分。
- 备选方向包括真实DMA观测下的共享轻量更新，以及在同一物理处理流程中比较确定性、扩散或其他生成先验。采用新网络前应固定观测、训练几何和总预算，比较完整CSI误差与在线代价。
- 泛化应区分同一分布的独立几何、新DMA矩阵、新角距分布和新频率/孔径。仅降低观测残差不能评价未观测信道分量。
