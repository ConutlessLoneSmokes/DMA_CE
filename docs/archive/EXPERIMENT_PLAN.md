# 候选A首轮实验预声明

2026-10-16，用户授权新建独立仓库、复用函数和开展实验。目标：判断同观测粗估的可计算可靠度，是否能改善条件残差生成恢复。

1. 真实球面少径信道，连续随机角距，不向估计器提供真实路径或粗中心。单RF微带的同一谐振状态同时决定全带响应；全部频点都有压缩观测。
2. 每个划分独立生成几何。同一几何在带宽/配置/SNR条件之间配对，跨划分不复用。只使用训练CSI的全局尺度和训练平均白化接收功率；不是逐样本等SNR。
3. 联合频率SBL从已知字典、DMA矩阵、观测和噪声方差估计CSI及后验对角。保留迭代次数和收敛状态，不读取真实支撑。可靠度为模型内方差代理，训练真值只用于统一尺度标定。
4. 四个同架构、同训练步数的网络：仅粗估条件的完整CSI扩散；仅粗估条件的残差扩散；可靠度条件残差扩散；可靠度条件确定性残差网络。无可靠度模型使用同尺寸零占位输入。
5. 残差目标的全局RMS只由训练集确定。所有扩散模型使用相同VP时序、确定性DDIM步数和配对初始噪声，不宣称逐式复现Jin原网络。
6. 可靠度在相同带宽/配置/SNR内跨场景打乱，区分局部可靠度和条件标签效应。所有残差方法分别开/关相同的末端加权观测一致性修正。
7. 一致性标量只根据无可靠度残差模型的验证NMSE，从预声明网格选择，再固定给所有方法；筛选集不选参。它是算法约束，不声称条件生成与重复似然相乘得到精确后验。
8. 输出完整CSI NMSE、行/零空间误差、观测残差、逐频误差、可靠度校准分组和计算时间。汇总先在线性域平均再转dB；配对区间按独立几何块bootstrap。
9. 首轮为单训练种子、缩小阵列的方法筛选。烟雾运行只检查连通性。不存在强制取得收益的停止标准；负结果保留。
10. 每个运行预设1800秒硬超时，保存配置、环境、源码ZIP、种子、数据/模型哈希、日志和逐场景指标。进程与输出持续监测。较大实验依据本轮结果再设计。

本轮不同时加入导频优化、未知硬件漂移或新的注意力模块。
