# 相干后验的误差分解与相位扰动

2026-10-28，用户授权开始解释相干更新成功与错误关联的代价。任务为[GitHub #5](https://github.com/ConutlessLoneSmokes/DMA_CE/issues/5)，主运行 `coherent_mechanism_20261028_v2`。配置见 `configs/coherent_mechanism.json`，入口为 `scripts/analyze_coherent_mechanism.py`。

## 固定输入与比较

复用 `coherent_delay_20261026_v1` 的32个原新几何与16个历史复核几何、五SNR及已保存预测，两队列分别处理。数据已经被读取过，本轮为事后机制分析；不做参数选择。原观测、空间方差gamma、候选索引、时延权重和平滑包络均固定，不重算SBL。

已有输出比较为 free→coherent_selected、free→coherent_half、free→shuffled_half、shuffled_half→coherent_half。新增相位对照仅在32个原新几何上计算，固定rho=0.5：将全部候选时延设为零；或将原归一化时延u统一增加0.25/K、0.5/K、1/K后模1。其余输入完全相同。原时延和打乱输出直接复用，第一批原相干后验另重放核对。

这里一个偏移单位为 $1/(K\Delta f)=1/B$，约33.33 ps，对应约9.99 mm路程；并非原128点搜索网格的一个间隔。¼、½、1单位在全频带大致引入¼、½、1周期的额外相位斜率。零时延对照保留低维平滑相关但去掉候选特有相位调制。

所有新增对照按预先固定的数值逐一报告，不根据CSI选择偏移或更换权重。计算上限1800秒；已有运行文件在前后逐哈希核对，新增输出保存到独立runs目录。

## 误差分解

令参考误差残差 $r=H-\widehat H_0$，修正 $d=\widehat H_1-\widehat H_0$，则

$$
\lVert H-\widehat H_1\rVert^2
=\lVert r\rVert^2+\lVert d\rVert^2-2\operatorname{Re}\langle r,d\rangle.
$$

逐频对实际白化矩阵做复双精度SVD，使用全部非零右奇异向量构造行空间投影，余量为零空间。完整误差、修正能量和交叉项在这两个正交子空间中分别计算；所有分量统一除以该场景完整真值能量，因此能够相加。方向余弦是每场景的实内积除以两向量范数后，再跨场景取平均。

逐场景表中 `before`、`after` 是误差，`correction` 为修正能量，`alignment` 为正号的两倍对齐内积，`gain=before-after=alignment-correction`。正gain表示改善。每个分量的均值与配对95%区间由几何成块bootstrap2000次计算；同队列各SNR共享抽样索引。

“零空间贡献比例”使用平均线性误差下降之比，不使用dB差相除。它还受原误差在零空间的能量占比影响，报告同时给出行空间和零空间各自的相对下降。

补充计算原估计相关核与各扰动核的Frobenius方向余弦，逐候选归一化后按保留相关方差gamma×时延权重质量加权，再跨场景平均。该指标的参照是原估计核，真值未进入；它用于检查打乱配对后保留了多少原核结构。

## 核验与产物

程序先用手工可算的复数例子核对改善方向、错误修正、零空间不变及复数旋转投影；实际运行核对投影正交、行零可加性、误差恒等式、父运行评分及原相干后验重放。独立核验采用观测Gram方程投影，与SVD路径交叉验证。

完整结果位于 `results/coherent_mechanism_20261028_v2/`，完整新增预测、源码、环境、配置及父输入哈希位于 `runs/coherent_mechanism_20261028_v2/`。父输入保持原位置，通过逐文件哈希绑定。主报告 `interpretation.md` 记录实际结论、负结果和下一步决定；没有在本轮训练网络。

首次v1已完成保存预测的全量分解，直接重复完整双精度字典后验时，本地GPU显存接近容量、后续批次吞吐不足，主动停止并保留状态与源码。v2在相同科学配置下复用全部相位对照共有的独立协方差Cholesky因子及信道—观测交叉矩阵，字典按频点分块计算，只有低秩相位项随对照改变。小尺寸结果与原完整后验逐值核对，实际首批再与父运行原相干输出核对。此计算调整不改变gamma、边缘方差、权重或任何对照。
