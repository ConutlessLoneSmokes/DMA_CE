# 时延分数与相干修正幅度标定

2026-10-28，用户授权下一步研究，[任务#6](https://github.com/ConutlessLoneSmokes/DMA_CE/issues/6)。本轮检验现有时延分数是否含有逐场景修正幅度信息，比较固定相干更新、常数幅度标定、分数条件幅度标定。固定相干先验rho=0.95，本轮标定的是输出CSI修正的步长lambda。

## 数据与先冻结顺序

配置 `configs/coherent_calibration.json`，运行 `coherent_calibration_20261028_v1`，入口 `scripts/probe_coherent_calibration.py`。初始单段计算预算1800秒；本地实测完整吞吐略超该预算，在所有系数冻结且新观测保存后，按两段各不超过1800秒续接，总耗时单独报告。样本数、方法和选择规则保持原样。

复用原512训练几何中前32个，只拟合小规模标定器；原512训练归一化、训练平均接收SNR功率标定与硬件保持原样。训练观测用独立白化噪声种子2026102803构造，五SNR共享标准噪声。验证使用相干探查已有前32几何缓存，选择正则系数。先冻结标定系数、训练统计、验证选择及源码哈希，再生成32个新筛选几何，种子2026102804。新几何与全部已知训练、验证和筛选几何逐ID检查不重叠。

每个SNR分别标定，五点为−10、0、10、20、30 dB。所有方法共用同一SBL100方差、自由后验及相干后验、观测、噪声和已知DMA矩阵；不重新搜索配置或训练神经网络。

## 分数与标定器

定义每候选保留时延权重质量为 $m_g=\sum_q w_{gq}$，使用在线分数

$$
s=\frac{\sum_{g\in\mathcal C}\gamma_gm_g}{\sum_g\gamma_g}.
$$

它是被保留相干分量覆盖的原子总方差份额。分数本身不称为校准概率。取logit后，仅用32训练几何计算每SNR均值与标准差，得到z。

令 $d=\widehat H_{coh}-\widehat H_{free}$，输出为 $\widehat H=\widehat H_{free}+\lambda d$。对照为自由后验、lambda=1的固定相干后验、仅常数lambda标定、lambda=clip(a+bz,0,2)的分数标定。常数版本也使用相同训练/验证信息和相同正则候选，以区分整体幅度调整与分数条件信息。

训练标签为 $c=\lVert d\rVert^2/\lVert H\rVert^2$ 和 $b=\operatorname{Re}\langle H-\widehat H_{free},d\rangle/\lVert H\rVert^2$。用加权最小二乘拟合lambda的线性模型，等价于最小化训练均值中的 $c\lambda^2-2b\lambda$；岭正则向lambda=1收缩，候选0、0.1、1、10。训练拟合不使用验证标签；验证只在固定候选中按实际截断lambda后的完整CSI平均线性NMSE选择正则，平局取更强正则。筛选时仅由当前分数、已冻结训练统计和系数确定lambda。

常数标定不依赖分数，分数标定允许斜率为正或负；不预先规定分数越大就必须使用更大步长。该分数已参与原相干先验，是否还含有剩余幅度信息由对照判断。

## 评价与诊断

主指标为逐几何完整CSI相对平方误差的线性均值再转dB。报告分数标定相对固定和常数标定的配对差及2000次几何bootstrap区间，五SNR共享抽样索引。另报告lambda分布、分数与lambda=1实际相对收益、事后最优单步幅度的逐SNR秩相关，避免用跨SNR共同趋势替代场景内预测能力。

真实误差只用于训练标签、验证选择及筛选评分/诊断。所有新增输入、完整预测、gamma、时延模型、冻结记录、环境、源码和逐场景结果保存到独立runs目录。运行前核对自由后验重建、二次误差恒等式、已知标定解、截断和固定lambda=1复现。
