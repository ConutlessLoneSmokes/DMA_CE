# 固定观测下的先验互补探查

2026-10-23，用户已授权小规模实验：研究SBL尚未利用的因素，核对其他方法是否利用，并检查能否结合取得完整CSI精度增益。方法形式不限扩散；优先−10至10 dB，高SNR希望与强SBL接近。约0.1 dB只是期望范围，不设专门验收检查，也不据此判定方法有问题。

本轮已完成，结果、机制对照与限制见[实验分析](../../results/prior_complementarity_20261023_v1/interpretation.md)。运行条件和对照按以下预声明执行，不以结果反向修改权重或候选。

## 本轮问题及控制

复用 `multirf_snr_20261022_v1` 的512训练、64验证几何、DMA状态、训练归一化、物理噪声和SNR功率校准。新建32个独立几何，扫描原9个SNR；同一几何的多个SNR成块配对，不作为独立重复。配置为 `configs/prior_complementarity_probe.json`，运行ID为 `prior_complementarity_20261023_v1`，至多15分钟。沿用原100步SBL作为直接参照，不重训网络，不把本轮称为论文主结果。

1. **训练统计的补充。** 比较SBL100与LS、验证已冻结收缩系数的LMMSE、逐频LMMSE。LS是只使用同一观测的控制；两种LMMSE都使用相同512份训练CSI的均值/协方差，区别是选定收缩保留部分跨频协方差，逐频版本删除跨频块。
2. **最小融合。** 对方向$D=\widehat H_B-\widehat H_{SBL}$，由每个SNR的64个验证几何选择单个实系数$w\in[0,1]$，最小化mean scene NMSE。融合为$\widehat H_{SBL}+wD$，不假定两个估计误差独立。主比较包括LS、选定LMMSE、逐频LMMSE三种方向；另测选定LMMSE的零空间方向及把选定LMMSE权重固定用于逐频版本的对照。参数冻结后才生成新筛选观测；不按筛选场景或真值选择权重。
3. **物理跨频关系的理想诊断。** 两条诊断都获得相同的真实几何及完整物理路径基，区别仅为逐频分别拟合3个复系数，或全频共用3个复系数。路径基保留真实总路程、吸收和反射幅频响应，不逐频归一化。真实几何仅进入这两条显式oracle诊断，不提供给实际方法；它们不是可部署性能，也不是无条件理论误差下界。

已保存的SBL100输入略优于充分SBL，本轮不以较慢但误差更高的版本替代它。新32几何不复用旧筛选数据；本轮结果看过后也只属于探索性筛选。

## 复核与解释

新权重公式用已知极小值例子检查；零空间投影用显式矩阵检查；两条oracle拟合做无噪声已知解检查。实验复核配置、源码、原输入哈希、几何无交集、观测共享、冻结顺序、评分及误差分解。完整配置、环境、源码、输入和逐场景输出保存在独立 `runs/<id>/`，必要导出在 `results/<id>/`。

沿用父运行的复数单精度保存预测，双精度进行融合计算、路径拟合和评分；主评分基于转换后实际保存的预测。原运行不清理。新缓存预计约1.9 GB，启动前检查实际输出盘空间。服务器持久盘空间不足，本轮按配置写入 `/tmp/dma_ce_probe_runs/<id>/` 内存临时盘，完整运行须在结束前复制至本地 `runs/<id>/` 并核对哈希；小型导出仍写入服务器 `results/<id>/`。

报告完整CSI的mean scene NMSE和物理MSE，配对区间仅覆盖固定训练/硬件下的新几何变化。未改善及负结果全部保留；数学检查只检查实现，不断言融合必须改善。

若LMMSE融合改善，只能直接支持其训练均值/协方差与SBL输出存在可用互补，不能自动归因跨频相关。选定与逐频版本在同权重下的对照用于进一步区分。若LS融合也改善，需要考虑一般收缩/偏差校正，而非独占学习先验解释。若物理oracle共用系数更好，只说明在几何已知的条件下该约束有价值，未知几何时的实际收益仍需可实现恢复器验证。

两种估计使用同一观测，不能把各自后验当作独立证据相乘并重复使用似然。简单凸融合不构成新颖性结论，负结果也不能否定所有结构化联合先验。
