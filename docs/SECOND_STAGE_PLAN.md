# 第二轮：充分迭代粗估与可靠度独立作用

2026-10-16，用户授权继续下一步。本轮沿用32阵元、32子载波和8个物理条件，保留第一轮训练/验证几何。筛选几何及噪声另用种子20261017，旧筛选结果只用于提出本轮问题。

1. 迭代预算只由第一轮64个验证几何确定。依次评价500、1000、2000、4000次；字典、阻尼和收敛阈值1e-3固定。选择满足以下条件的较小预算：总体收敛率至少95%、每条件至少90%，并且加倍预算后各条件线性均值NMSE转dB的变化不超过0.1 dB、平均后验方差变化不超过5%。满足即停止扩大；不满足则保留诊断并进一步处理，不称其为充分迭代基线。
2. SBL迭代中只计算更新需要的系数后验，最终再计算信道后验。用稠密计算对照验证该省算不改变迭代结果。
3. 在选定预算下重新生成训练和验证粗估、后验方差及训练标定。训练两套同架构确定性残差CNN：不输入可靠度、输入可靠度。参数初始化、训练批次、更新数2000均相同。无可靠度使用零占位，参数量一致。
4. 对有可靠度模型，将可靠度在相同物理条件内跨几何打乱，初估和模型权重固定。该消融用于判断模型是否使用对应场景的可靠度。
5. 三组网络输出及SBL均开关相同的末端观测一致性修正，共8组方法。公共系数只按无可靠度网络的验证NMSE，从0、0.1、1、10选择；0表示完全保留原估计。
6. 模型与公共系数冻结后评价新的128个筛选几何。输出逐场景完整CSI NMSE、行/零空间误差、观测残差、可靠度校准、时间及按独立几何块的配对区间。训练标签和评分可使用真值，估计输入不包含真值。
7. 主要比较：有/无可靠度；打乱/正确可靠度；两套网络各自相对充分迭代SBL。原始和修正输出分别报告，不以筛选结果重选方法或系数。
8. 本轮为单训练种子的机制筛选，保留负结果。每次运行保存独立配置、环境、源码、冻结与逐场景结果；1800秒超时。完整尺寸、多种子和扩散训练量对照另行设计。
