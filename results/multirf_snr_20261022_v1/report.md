# 多RF DMA的四方法SNR比较

单组训练几何、单组DMA状态、单次网络初始化的探索性实验。
阵列：4条微带，每带256单元；J=32。
独立几何：训练512、验证64、筛选128。
横轴是训练平均的每复观测接收SNR；纵轴先平均逐场景线性NMSE，再转dB。四方法共用观测和物理噪声。
验证冻结：LMMSE收缩系数=0.9；DDPM断点=8000；一致性倍率=0.0。
SBL未收敛输出8个，仍包含于曲线；完整记录见metrics.csv。
DDPM为当前SBL条件残差模型，在本阵列上重新训练；多次DDIM输出平均后执行一次观测一致性更新。
区间只覆盖固定训练/硬件下的筛选几何波动。完整配置、源码、模型、观测和预测已归档。
